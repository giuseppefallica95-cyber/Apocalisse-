# Apocalisse — World Wiki

Wiki interattiva personalizzata per una campagna D&D / worldbuilding di lungo periodo.

## Architettura

- `index.html` — interfaccia web della wiki
- `assets/styles.css` — stile
- `assets/app.js` — navigazione, ricerca, modalità DM/Player, timeline, relazioni e mappa
- `data/world.js` — fonte dati strutturata
- `world/` — schede canoniche in Markdown
- `CANON_PROTOCOL.md` — protocollo del canone

## Stati del canone

- `CANON`
- `DRAFT`
- `RUMOR`
- `SECRET`
- `RETCON`

La repository è la fonte canonica condivisa tra il worldbuilding e la wiki pubblicata.
